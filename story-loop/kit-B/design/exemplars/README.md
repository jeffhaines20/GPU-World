# Exemplar texts go here

One file per story, the text the human supplied. Any readable form works — `.txt`, `.md`, text pasted
out of an ebook reader, a PDF you can select text in. A scan you cannot select text from does not count,
because a judge cannot read it. The file name does not matter; `design/EXEMPLARS.md` is the register that
says which file is which story, and its "Text supplied" column is what the loop reads.

These are the human's own copies. Nothing from them is reproduced in the manuscript, and a comparison
quotes at most one sentence from each side as evidence.

This folder is empty until intake. An empty folder is not an error: it means every comparison will be
made from the judges' knowledge of the stories, which the records mark `from_memory: true` and which the
gate counts as weaker evidence.
